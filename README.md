# MouseExpert 滑鼠專家訓練營

繁體中文滑鼠技能分級訓練網頁，參考舊作「滑鼠小達人訓練場」（https://lphky.github.io/mouse/）的概念重新設計。適合小學至初中學生在電腦室、家中或由老師投影示範使用。

公開網站：https://lphky.github.io/MouseExpert/

## 內容

七項技能，每項分入門、熟練、專家三級：

| 技能 | 入門 | 熟練 | 專家 |
|---|---|---|---|
| 🎯 移動與停留 | 100px 圓形停 1 秒 | 70px 停 1.5 秒 | 沿 50px 闊彎曲路線由起點走到終點 |
| 👆 單擊 | 90px 靜止目標 | 60px，每 2 秒換位置 | 44px 移動目標＋1–2 個紅色干擾物 |
| ✌️ 雙擊 | 100px，0.8 秒內 | 70px，0.55 秒內 | 50px，0.4 秒內 |
| ✋ 拖放 | ⭐拖入綠色區 | 拖入同色區 | 三個檔案分類入資料夾 |
| 📋 右鍵選單 | 3 個選項 | 4 個選項 | 6 個選項、兩個檔案只可右鍵指定一個 |
| 🖱️ 滾輪捲動 | 30 項，目標在中段 | 30 項，位置隨機（可能要向上捲） | 60 項，有相似干擾項 |
| 🖥️ 模擬桌面 | 2 步任務 | 3 步任務 | 4 步任務 |

移動與停留專家級會即時畫出走過的路；走出路線時保留該次路線（紅色虛線）、標示走出位置（✗）及最遠到過的位置（⭐），並按進度給鼓勵。雙擊的第一下及第二下各有擴散圓圈動畫，第二下變綠色並顯示「2✓」。

每級 10 題（模擬桌面每級 5 題）。完成七項「熟練」級各 1 星後解鎖 20 題「專家測驗」，準確度 85% 或以上合格，可生成並列印證書。

## 星級規則

- 準確度 = 成功次數 ÷（成功次數＋錯誤次數）；平均時間 = 每題由出現到完成的平均秒數。
- 完成該級 = 1 星；準確度 ≥ 80% = 2 星；準確度 ≥ 90% 且平均時間不超過標準時間 = 3 星。
- 取得 1 星即解鎖同技能下一級。

各級標準時間（秒）：

| 技能 | 入門 | 熟練 | 專家 |
|---|---|---|---|
| 移動與停留 | 2.5 | 3.0 | 6.0 |
| 單擊 | 2.5 | 2.0 | 1.5 |
| 雙擊 | 3.0 | 2.5 | 2.0 |
| 拖放 | 4.0 | 4.0 | 8.0 |
| 右鍵選單 | 5.0 | 4.5 | 4.5 |
| 滾輪捲動 | 6.0 | 7.0 | 9.0 |
| 模擬桌面 | 8.0 | 14.0 | 20.0 |

移動與停留的標準時間已包括停留所需時間；模擬桌面的標準時間是整個多步驟任務的時間。

## 本機開啟

使用了 ES Modules，需經本機伺服器開啟（直接雙擊 index.html 會被瀏覽器阻擋）：

```bash
python3 -m http.server 4180
# 打開 http://localhost:4180/
```

不需要網絡、不使用外部字體或 CDN。

## 部署到 GitHub Pages

GitHub repo `lphky/MouseExpert`，Settings → Pages → Deploy from a branch → `main` / `(root)`。所有路徑都是相對路徑。`node_modules/`、`test-results/` 不會上傳。

## 檔案結構

- `index.html`、`css/style.css`、`icon.svg`
- `js/config.js`：**所有難度參數**（目標大小、雙擊門檻、題數、標準時間、星級條件、測驗合格線）
- `js/app.js`：畫面（首頁、技能地圖、示範、練習、結果、測驗、證書、設定）
- `js/engine.js`：每題的計時、計分、暫停、成功／錯誤回饋
- `js/skills/*.js`：七項技能
- `js/input.js`：自行判斷的雙擊、Pointer Events 拖放、自製右鍵選單
- `js/scoring.js`：星級、建議、解鎖、測驗規則（純函數，有單元測試）
- `js/storage.js`、`js/audio.js`、`js/demo.js`

## 資料保存

只保存在該瀏覽器的 LocalStorage，鍵名 `mouseexpert.v1`：暱稱、設定、每技能每級的最佳星數／準確度／平均時間／完成次數、測驗紀錄及證書。不上傳、不追蹤、沒有排行榜。資料壞了會自動重設並提示；私隱模式等無法儲存時仍可練習，並提示「這次的進度不會被保存」。

**清除進度：** 右上角 ⚙️ 設定 → 「清除所有進度」→ 確定。

## 設定

音效、大目標模式（目標放大 1.5 倍，結果標示「大目標」）、減少動態效果（預設跟隨系統）、老師模式（解鎖全部關卡，結果不寫入紀錄）。

## 觸控裝置

首次偵測到手指操作時提示一次。單擊、雙擊（門檻放寬至 0.8 秒）、拖放可用手指練習；移動與停留、右鍵選單、滾輪捲動、模擬桌面及專家測驗需要滑鼠。視窗小於 600×500 時練習會暫停並提示放大視窗。練習中按 P 鍵可暫停／繼續；技能地圖右上方的「建議下一步」會指向下一個未拿星（或未滿三星）的級別。
